# Birthday Gift — Salwa Safitri (Iwa)

Website ulang tahun pink pastel yang bisa dipublikasikan dengan GitHub Pages.

## Isi folder
- `index.html` — struktur halaman
- `style.css` — tampilan responsif
- `script.js` — countdown dan interaksi
- `images/` — tempat foto
- `music/` — tempat musik MP3
- `videos/` — tempat video kenangan (opsional)

## Personalisasi
1. Ganti `BIRTHDAY_DATE` di `script.js` dengan tanggal ulang tahun Salwa. Format contoh: `2026-11-23T00:00:00+07:00`.
2. Unggah foto ke `images/` dengan nama persis `foto-1.jpg`, `foto-2.jpg`, dan `foto-3.jpg`.
3. Unggah musik yang boleh kamu bagikan ke `music/lagu.mp3`.
4. Opsional: unggah video ke `videos/kenangan.mp4`.
5. Commit perubahan di GitHub.

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Musik tidak otomatis diputar; pengunjung perlu menekan tombol Putar musik.
